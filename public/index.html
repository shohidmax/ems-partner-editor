Open-Meteo API Cheat-Sheet

আপনার নিজস্ব Open-Meteo সার্ভারের (weatherapi.espserver.site) জন্য সম্পূর্ণ এবং কাস্টমাইজড API ডকুমেন্টেশন। যেহেতু আপনার সার্ভারে এখন লাইভ এবং হিস্টোরিক্যাল— দুই ধরনের ডেটাবেসই রেডি আছে, তাই আপনার ড্যাশবোর্ড বা যেকোনো প্রজেক্টে ডেটা কল করার জন্য এই ডকুমেন্টেশনটি একটি চিট-শিট হিসেবে কাজ করবে।

🌐 Base URL (মূল লিংক)

GET https://weatherapi.espserver.site/v1/forecast

রেসপন্স ফরম্যাট: JSON

১. লাইভ এবং ফোরকাস্ট ডেটা API (Live Dashboard-এর জন্য)

আপনার ড্যাশবোর্ডের বর্তমান অবস্থা এবং টাইমলাইনের জন্য এই API টি ব্যবহার করবেন। এটি dwd_icon মডেল ব্যবহার করে।

  • latitude & longitude: লোকেশনের কোঅর্ডিনেট (যেমন: 24.3745, 88.6042)
  • current: রিয়েল-টাইম ডেটার তালিকা।
  • minutely_15: প্রতি ১৫ মিনিটের টাইমলাইন ডেটা।
  • timezone: auto (সার্ভার নিজে থেকে লোকাল টাইম জোন সেট করে নেবে)।
  • models: dwd_icon
https://weatherapi.espserver.site/v1/forecast?latitude=24.3745&longitude=88.6042¤t=temperature_2m,apparent_temperature,relative_humidity_2m,rain,weather_code,wind_speed_10m,shortwave_radiation&minutely_15=temperature_2m,relative_humidity_2m,rain&timezone=auto&models=dwd_icon

২. হিস্টোরিক্যাল ডেটা API (গ্রাফ ও ট্রেন্ড অ্যানালাইসিসের জন্য)

২০২৪ থেকে শুরু করে আজকের দিন পর্যন্ত পেছনের যেকোনো দিনের ডেটা বের করার জন্য এটি ব্যবহার করবেন। এটি আপনার ডাউনলোড করা বিশাল copernicus_era5 মডেল ব্যবহার করে।

  • start_date: শুরুর তারিখ (YYYY-MM-DD ফরম্যাটে)।
  • end_date: শেষের তারিখ (YYYY-MM-DD ফরম্যাটে)।
  • hourly: প্রতি ঘণ্টার ডেটার তালিকা।
  • models: copernicus_era5
https://weatherapi.espserver.site/v1/forecast?latitude=24.3745&longitude=88.6042&hourly=temperature_2m,apparent_temperature,relative_humidity_2m,precipitation,weather_code,wind_speed_10m,shortwave_radiation&start_date=2024-01-01&end_date=2026-06-06&timezone=auto&models=copernicus_era5

(⚠️ নোট: হিস্টোরিক্যাল মডেলে বৃষ্টির জন্য rain এর বদলে precipitation ব্যবহার করতে হবে)।

📊 ডেটা ডিকশনারি (Variables Explanation)

ParameterDescriptionUnit
temperature_2mভূপৃষ্ঠ থেকে ২ মিটার ওপরে বাতাসের তাপমাত্রা°C
apparent_temperatureরোদ, আর্দ্রতা ও বাতাস মিলিয়ে অনুভূত তাপমাত্রা (Feels Like)°C
relative_humidity_2mবাতাসে জলীয় বাষ্পের পরিমাণ বা আর্দ্রতা%
rainবৃষ্টির পরিমাণ (শুধুমাত্র লাইভ/ফোরকাস্ট মডেলের জন্য)mm
precipitationমোট বৃষ্টিপাত (শুধুমাত্র হিস্টোরিক্যাল ERA5 মডেলের জন্য)mm
wind_speed_10mভূপৃষ্ঠ থেকে ১০ মিটার ওপরে বাতাসের গতিবেগkm/h
shortwave_radiationসৌর বিকিরণ বা রোদের তীব্রতাW/m²
dew_point_2mশিশিরাঙ্ক°C
weather_codeআবহাওয়ার ধরন বোঝানোর জন্য WMO কোডCode (0-99)

⚡ WMO Weather Codes (আপনার অ্যালার্ট সিস্টেমের জন্য)

  • 0 - 3: আকাশ পরিষ্কার বা সামান্য মেঘলা (Clear / Partly Cloudy)
  • 45, 48: কুয়াশা (Fog)
  • 51, 53, 55: গুঁড়ি গুঁড়ি বৃষ্টি (Drizzle)
  • 61, 63, 65: মাঝারি থেকে ভারী বৃষ্টি (Rain)
  • 80, 81, 82: মুষলধারে বৃষ্টি / বৃষ্টিপাত (Rain Showers)
  • 95: বজ্রঝড় / বিজলি চমকানো (Thunderstorm) ⚠️ আপনার ড্যাশবোর্ডের রেড অ্যালার্ট
  • 96, 99: শিলাবৃষ্টিসহ ভয়াবহ বজ্রঝড় (Thunderstorm with hail) ⚠️ আপনার ড্যাশবোর্ডের রেড অ্যালার্ট
